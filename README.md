# Session Lens

Session Lens — an offline viewer for macOS that opens agent session logs (JSONL transcripts and diffs) and shows a timeline of prompts and tool calls next to a side-by-side diff. No network.

- Web page: https://dcreations.fr/session-lens/
- Privacy: https://dcreations.fr/session-lens/privacy/ (the app collects no data)
- Releases: see the Releases page of this repo. The newest is marked "Latest"; older versions stay available.

## Build
1. Install Xcode 26 and XcodeGen (`brew install xcodegen`).
2. Run `xcodegen generate` in this folder.
3. Open the generated project, set your own signing team, and run.
